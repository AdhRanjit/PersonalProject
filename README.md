# 🛡️ Transaction Audit and Fraud Detection Platform

This is a Spring Boot-based backend system that simulates a real-time financial transaction logging and fraud detection engine. The project is designed to mirror some of the use cases in financial institutions like BNY Mellon — providing secure, auditable, and rule-based monitoring for financial transactions.

---

## 🚀 Features

- REST API for logging and retrieving transactions
- Rule-based fraud detection system
- In-memory or H2-based data persistence
- Periodic fraud scanning using Spring Scheduler
- Email alert system for flagged transactions (optional)
- Easy-to-run locally with no external dependencies

---

## 🛠️ Tech Stack

- Java 17+
- Spring Boot
- Spring Web, Spring Data JPA
- H2 Database (In-memory or file-based)
- Spring Scheduler
- JUnit + Mockito for unit testing
- Maven
